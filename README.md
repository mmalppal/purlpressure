# purlpressure.com

Marketing + content site for [Purl Pressure](https://www.instagram.com/purlpressure/).

Built with Astro 5, MDX, deployed to Vercel.

## Dev

```bash
npm install
npm run dev          # http://localhost:4321
npm run build
npm run preview
```

## Adding a Weekly Obsessions post

Duplicate any file in `src/content/obsessions/`, update the frontmatter, write body, push to `main`. Vercel auto-deploys.

See [`CLAUDE.md`](./CLAUDE.md) for the full project context.
